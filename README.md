# Air Quality Index (AQI) Excel Dashboard

## Project Overview
This project presents an interactive Air Quality Index (AQI) dashboard built using Microsoft Excel to analyze pollution levels and environmental data. The dashboard enables users to explore air quality trends and compare pollution levels across different regions.

## Objectives
- Analyze AQI data to identify pollution trends
- Create an interactive dashboard for data visualization
- Perform data summarization using Excel tools
- Enable comparative analysis of air quality levels

## Dataset
The project uses an Air Quality Index dataset containing 3,000+ records of pollution data.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts and Graphs
- Data Filtering
- Data Visualization

## Features
- Interactive dashboard design
- Dynamic filtering and sorting
- Visual comparison of AQI levels
- Data summarization using pivot tables

## Project Workflow
1. Data cleaning and preparation
2. Data summarization using pivot tables
3. Dashboard creation using charts
4. Data visualization and analysis
